# Ride Trainer 4×8 — Installable PWA

This is an installable Progressive Web App.

## Android / Chrome
1. Host this folder on an HTTPS site (GitHub Pages is an easy option).
2. Open the site in Chrome on your phone.
3. Choose **Add to Home screen** / **Install app**.
4. Launch Ride Trainer from the new icon.

The app is designed to work offline after its first successful load.

## Local testing
A `file://` URL will not provide PWA installation. Use an HTTPS host or a local web server.

## Included workout
20:00 warm-up → 5:00 steady → 30s spin-up/60s easy ×3 → 4:00 easy → 8:00 hard/4:00 easy ×4 → 1:00 very hard/2:00 easy ×4 → 10:00 cooldown.
